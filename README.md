
# Expense Tracker

## 1. Project Overview
Expense Tracker is a web application that helps users
record income and expenses and calculate their balance.

## 2. Objectives
- Record daily income and expenses.
- Calculate total income, expenses, and balance.
- Organize transactions by category.
- Filter transactions by type.
- Store transaction data in browser storage.

## 3. Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- GitHub

## 4. Features
- Add income and expense transactions.
- View transaction history.
- Delete transactions.
- Filter income and expenses.
- Automatically calculate the balance.
- Retain transactions after browser refresh.

## 5. Project Structure
ExpenseTracker/
- index.html
- style.css
- script.js
- README.md

## 6. How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Add transactions using the form.

## 7. Calculation
Balance = Total Income - Total Expenses

## 8. Storage
Transactions are saved in the browser using Local Storage.

## 9. Limitations
Data is stored locally in the browser and is not
synchronized across different devices.

## 10. Conclusion
The project demonstrates how HTML, CSS, and JavaScript
can be combined to build a functional expense management
application with transaction tracking and automatic
calculations.
